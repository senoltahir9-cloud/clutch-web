# ClutchApp ücretsiz indirme sitesi

Bu klasör Netlify Free üzerinde yayınlanacak şekilde hazırlandı.

## Ücretsiz yayın

1. https://app.netlify.com/drop adresini açın.
2. `ClutchApp-download-site-publish.zip` dosyasını sürükleyip bırakın.
3. Netlify ücretsiz bir `...netlify.app` adresi verir.
4. Netlify panelinde Forms bölümünde `clutchapp-downloads` kayıtlarını görürsünüz.

## İndirme akışı

- Kullanıcı e-posta ve rol bilgisini girer.
- Form Netlify Forms'a kaydedilir.
- Kayıttan sonra Windows ZIP indirme linki açılır.

## Güncelleme

Yeni Windows sürümü üretildiğinde `downloads/ClutchApp-Setup-1.0.0-latest.zip` dosyasını yenileyip siteyi tekrar Netlify'a yükleyin.
